## 2. 策略定义

### 2.1 Alpha144

对股票 `s` 在交易日 `t` 计算：

```text
impact(s, i) = abs(adj_close(s, i) / adj_close(s, i-1) - 1) / amount(s, i)

Alpha144(s, t) =
    sum(impact(s, i), i属于最近20日且日收益<0)
    / 最近20日下跌日数量
```

- 收益率使用复权收盘价，避免分红送转制造机械价格缺口。
- 成交额使用年度特征快照中的 `liq_amount`。
- Alpha144 越大，代表单位成交额对应的下跌价格冲击越大，即流动性越差。
- 最近20日没有下跌日时，因子记为空，不进入当期候选池。

### 2.2 候选池与入场

1. 使用信号日可知的中证500历史成分，不使用当前成分回填历史。
2. 每10个交易日按 Alpha144 从大到小排序，取前15%作为候选池。
3. 因子池刷新后的每个交易日，都检查池内股票是否满足：

   ```text
   当日复权收盘价 > 此前5个交易日最高复权收盘价
   ```

4. 信号在收盘后生成，下一交易日开盘买入，不允许收盘信号同日成交。
5. 最多持有5只；每个新仓目标金额为开盘时总资产的20%。已有仓位不做每日再平衡。

### 2.3 离场与大盘过滤

- 个股不设止损。
- 买入后持满20个交易日，在下一交易日开盘卖出。
- 中证500指数20日收益严格低于 -3% 时，收盘生成清仓信号，下一交易日开盘尝试卖出，同时停止新开仓。
- 大盘过滤恢复后，继续对当前因子池检查突破信号。

### 2.4 撮合约束

- 初始资金：1亿元。
- 买入成本：8bp；卖出成本：13bp。
- 收益和持仓估值使用复权价格；交易流水同时保留未复权开盘价。
- 主板按10%、创业板和科创板按20%检查开盘涨跌停。
- 开盘涨停时取消买单；开盘跌停时卖单顺延到下一个可交易开盘。
- 停牌期间按最后可用复权收盘价估值，卖单在恢复交易后执行。

## 3. 数据与防偏差处理

| 项目 | 口径 |
|---|---|
| 股票行情 | `db/feature_snapshots/model_features_2020..2026.parquet` |
| 股票池 | Baostock `query_zz500_stocks(date=信号日)` 点时成分 |
| 大盘指数 | Baostock `sh.000905` 日线 |
| 股票代码 | QuantMind 内部统一 `SH600000` 前缀格式 |
| 信号时点 | T日收盘后 |
| 成交时点 | T+1交易日开盘 |

历史成分必须标准化后恰好500只，且成分生效日不得晚于信号日。Baostock 个别日期只返回499只时，程序不会接受残缺快照，而是向前寻找最近的完整历史快照；所有请求结果保存在本地缓存。

本地 Qlib 的 `IDX_SH000905` 序列经核验存在日期/数值错位。例如它把2021年中证500收益算成约 -6.5%，而 Baostock 真实年度收益约 +15.6%。因此正式回测不使用该 Qlib 指数序列。

## 6. 交易审计

- 买入392次，已平仓387次，期末仍持有5只。
- 已平仓胜率46.51%，单笔平均净收益1.33%。
- 持满20日退出165次，胜率60.00%，平均净收益5.19%。
- 大盘过滤退出222次，胜率36.49%，平均净收益 -1.53%。这只是条件统计，不能单独证明去掉过滤会更好。
- 全样本空仓日占比27.29%，平均持仓3.60只。
- 开盘涨停拒绝买入1次，缺失开盘/停牌导致卖出重试9次，未出现开盘跌停顺延。
- 最大单笔盈利约205.30%，最大单笔亏损约 -34.11%。少数极端收益对集中持仓策略影响很大。

## 7. 与宣传结果差异较大的原因

1. **因子分层强度没有复现。** 当前样本的Q1至Q5不单调，策略最核心的横截面假设明显弱于宣传数据。
2. **大盘过滤并未消除系统性风险。** 策略仍有0.555的Beta，2024年在中证500上涨时反而亏损13.63%。
3. **公开策略卡片缺少复现细节。** 成交额单位、复权体系、指数成分版本、因子刷新后是否每日扫描、费用和涨跌停细节都会改变结果。本报告采用可解释且无未来函数的固定口径，不反向调参拟合宣传值。
4. **集中持仓导致路径依赖。** 最多5只股票使少量极端个股显著影响组合净值。
5. **容量约束尚未进入收益模型。** 1亿元资金意味着单只新仓目标约2,000万元，而策略专门选择低流动性股票。未设置成交额参与率和冲击滑点，当前结果仍可能高估实盘可实现收益。

## 8. 已知限制

- 缺少历史逐日ST标签，无法完整执行ST股票5%涨跌停规则；不能把本回测描述为完整的“含所有涨跌停制度”结果。
- 缺少退市现金结算状态。长期停牌按最后价估值、恢复后卖出，对最终退市股票可能偏乐观。
- 没有成交额参与率、冲击成本和滑点模型，1亿元只用于收益比例模拟，不代表真实容量。
- 2026年只统计到5月15日，不是完整年度。
- 历史表现不代表未来收益，不构成投资建议。
